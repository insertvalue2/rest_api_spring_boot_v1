# board-detail 글 상세

종류: 기능
배울 것: 사용자 예외, 전역 예외 처리 404

## 할 일
- S1 GET /api/boards/{id}가 글 하나를 작성자 번호, 작성자 아이디와 함께 돌려준다
- S2 없는 글 번호를 요청하면 404와 "게시글을 찾을 수 없습니다"를 공통 응답 모양으로 돌려준다
- S3 처리하지 못한 오류(예: 글 번호에 abc)는 500과 "관리자에게 문의하세요"를 공통 응답 모양으로 돌려준다
- S4 없는 주소를 요청하면 404를 공통 응답 모양으로 돌려준다

## 요청과 응답
GET /api/boards/4
응답: { "status": 200, "msg": "성공", "body": { "id": 4, "title": "제목4", "content": "내용4", "userId": 2, "username": "cos" } }

GET /api/boards/99
응답: { "status": 404, "msg": "게시글을 찾을 수 없습니다", "body": null }

## 흐름
GET /api/boards/{id} -> 글과 작성자 조회 -> 있으면 상세 응답 / 없으면 예외 -> 전역 예외 처리 -> 공통 실패 응답

## 안 하는 것
- 댓글 목록: reply 장
- 내 글 표시(owner): board-owner 장
- 400, 401, 403 예외: 그 상태가 처음 나오는 장
