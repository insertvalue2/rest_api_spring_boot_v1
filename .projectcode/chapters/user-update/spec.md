# user-update 내 정보 수정

종류: 기능
배울 것: 빈 비밀번호 유지, 조건부 검증

## 할 일
- S1 PUT /api/users/me가 로그인 토큰과 이메일, 비밀번호를 받아 내 정보를 고치고 id, username, email을 돌려준다
- S2 비밀번호 칸이 비어 있으면 비밀번호는 바꾸지 않고 이메일만 고친다 (기존 비밀번호로 계속 로그인된다)
- S3 비밀번호에 글자가 있으면 새 비밀번호로 바뀌고 BCrypt로 저장된다 (새 비밀번호로 로그인된다)
- S4 비밀번호에 글자가 있는데 4~20자가 아니면 400과 "비밀번호는 4~20자여야 합니다"를 돌려준다
- S5 이메일이 비었거나 형식이 틀리면 400과 "이메일을 입력해주세요" 또는 "이메일 형식이 올바르지 않습니다"를 돌려준다
- S6 토큰 없이 부르면 401이다

## 요청과 응답
PUT /api/users/me (ssar 토큰)
요청: { "email": "ssar@nate.com", "password": "" }
응답: { "status": 200, "msg": "성공", "body": { "id": 1, "username": "ssar", "email": "ssar@nate.com" } }

## 흐름
PUT /api/users/me -> 입력 검사(비밀번호는 비었거나 4~20자) -> 토큰의 회원 찾기 -> 비밀번호가 있으면 암호화, 없으면 기존 값 -> 값만 바꾸기(변경 감지) -> 응답

## 안 하는 것
- 아이디 바꾸기: 안 만듦
- 현재 비밀번호 확인: 안 만듦
