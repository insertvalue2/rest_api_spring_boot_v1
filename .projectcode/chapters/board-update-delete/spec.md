# board-update-delete 글 수정과 삭제

종류: 기능
배울 것: 작성자 검사 403, 변경 감지

## 할 일
- S1 GET /api/boards/{id}/edit가 작성자에게 수정 화면에 채울 제목과 내용을 돌려준다
- S2 PUT /api/boards/{id}가 작성자의 제목, 내용 수정을 받아 고치고 고친 글을 돌려준다
- S3 DELETE /api/boards/{id}가 작성자의 글을 지우고, 지운 글은 상세에서 404가 된다
- S4 남의 글을 수정 정보 조회, 수정, 삭제하면 403과 "게시글에 접근할 권한이 없습니다", "게시글을 수정할 권한이 없습니다", "게시글을 삭제할 권한이 없습니다"를 돌려준다
- S5 없는 글을 수정 정보 조회, 수정, 삭제하면 404와 "게시글을 찾을 수 없습니다"를 돌려준다
- S6 수정할 제목이나 내용이 비었거나 너무 길면 글쓰기와 같은 400 문구를 돌려준다
- S7 수정 정보 조회(GET .../edit)는 토큰이 없으면 401이다. 글 상세(GET /api/boards/{id})는 그대로 열려 있다

## 요청과 응답
PUT /api/boards/1 (ssar 토큰)
요청: { "title": "제목1 수정", "content": "내용1 수정" }
응답: { "status": 200, "msg": "성공", "body": { "id": 1, "title": "제목1 수정", "content": "내용1 수정", "username": "ssar", "createdAt": "..." } }

DELETE /api/boards/4 (ssar 토큰, cos의 글)
응답: { "status": 403, "msg": "게시글을 삭제할 권한이 없습니다", "body": null }

## 흐름
요청 -> 글 찾기(없으면 404) -> 작성자와 로그인 사용자 비교(다르면 403) -> 수정은 엔티티 값만 바꾸면 트랜잭션 끝에 UPDATE / 삭제는 DELETE -> 응답

## 안 하는 것
- 글을 지울 때 댓글 함께 지우기: reply 장
- 관리자의 남의 글 삭제: admin-api 장
