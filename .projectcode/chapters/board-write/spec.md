# board-write 글쓰기

종류: 기능
배울 것: 로그인 사용자 꺼내기, 저장 트랜잭션

## 할 일
- S1 POST /api/boards가 로그인 토큰과 제목, 내용을 받아 로그인한 사람의 글로 저장하고 id, title, content, username을 돌려준다
- S2 저장한 글은 글 목록 첫 줄(최신 글)에 나온다
- S3 토큰 없이 글을 쓰면 401과 "로그인 후 이용해주세요"를 돌려준다
- S4 제목이나 내용을 비우면 400과 "제목을 입력해주세요" 또는 "내용을 입력해주세요"를 돌려준다
- S5 제목이 100자, 내용이 1000자를 넘으면 400과 "제목은 100자 이하로 입력해주세요" 또는 "내용은 1000자 이하로 입력해주세요"를 돌려준다

## 요청과 응답
POST /api/boards
요청 헤더: Authorization: Bearer eyJ...
요청: { "title": "제목6", "content": "내용6" }
응답: { "status": 200, "msg": "성공", "body": { "id": 6, "title": "제목6", "content": "내용6", "username": "ssar", "createdAt": "..." } }

## 흐름
POST /api/boards -> JWT 필터가 로그인 사용자 확인 -> 입력 검사 -> 로그인 사용자를 작성자로 글 저장(쓰기 트랜잭션) -> 저장한 글 응답
