# admin-roles 회원 역할 바꾸기

종류: 기능
배울 것: 컬렉션 값 바꾸기, 역할 검사

## 할 일
- S1 PUT /api/admin/users/{id}가 ADMIN 토큰과 역할 목록을 받아 그 회원의 역할을 바꾸고 id, username, roles를 돌려준다. 같은 역할이 여러 번 오면 하나로 친다
- S2 바뀐 역할은 그 회원이 다시 로그인해 받은 토큰부터 적용된다 (ssar을 ADMIN으로 바꾸면 새 토큰으로 관리자 주소를 쓸 수 있다)
- S3 없는 회원이면 404와 "회원을 찾을 수 없습니다"를 돌려준다
- S4 역할 목록이 비었으면 400과 "역할을 설정해주세요"를 돌려준다
- S5 USER, ADMIN 말고 다른 역할이 있으면 400과 "역할은 USER, ADMIN 만 사용할 수 있습니다"를 돌려준다
- S6 지금과 같은 역할이면 400과 "현재와 같은 역할입니다"를 돌려준다

## 요청과 응답
PUT /api/admin/users/1 (cos 토큰)
요청: { "roles": ["USER", "ADMIN"] }
응답: { "status": 200, "msg": "성공", "body": { "id": 1, "username": "ssar", "roles": ["USER", "ADMIN"] } }

## 흐름
PUT /api/admin/users/{id} -> 관리자 규칙 통과 -> 입력 검사 -> 회원 찾기 -> 허용된 역할인지, 지금과 같은지 검사 -> 역할 목록을 비우고 새로 채움(변경 감지) -> 응답

## 안 하는 것
- 이미 받은 토큰의 역할을 바로 바꾸기: 안 만듦
